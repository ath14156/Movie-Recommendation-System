# 🎬 Movie Recommendation System

An end-to-end Machine Learning project that recommends similar movies using **Content-Based Filtering**, **TF-IDF Vectorization**, and **Cosine Similarity**.

---

## Features

- Interactive Streamlit Dashboard
- Movie Recommendation Engine
- Dataset Analytics
- Recommendation Insights
- Data Cleaning Pipeline
- Exploratory Data Analysis (EDA)

---

## Dataset

MovieLens Latest Small Dataset

- 9,742 Movies
- 100,836 Ratings
- 610 Users

---
